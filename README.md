# Student API

**Developer:** Timur Baigashev

## Project Description

Student API is a Spring Boot REST application for managing student records using PostgreSQL.

## CRUD Operations

- Create a student.
- Retrieve all students.
- Retrieve a student by ID.
- Update a student.
- Delete a student.

## Improvement

The GET operation for retrieving a student by ID returns HTTP 404 Not Found when the requested student does not exist.

## Technologies

- Java 17
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- PostgreSQL
- Maven
